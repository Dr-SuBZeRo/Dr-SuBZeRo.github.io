HOW I BUILD

Technology with principles.

Good software should solve a problem without creating unnecessary dependencies or taking more from people than it gives.

01
◈

Privacy by design

Collect as little as possible. Avoid tracking and unnecessary permissions. Keep personal data under the user's control.

02
⌁

Offline first

Core features should work without an internet connection wherever the product allows it.

03
∞

Free to use

No advertisements, subscriptions or in-app purchases. Useful tools should remain accessible.

04
⌘

Open development

Public repositories, transparent release notes and a clear path for feedback and contributions.
