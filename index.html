ENGINEERING PRINCIPLES

Intentional by
default.

Technology should serve the user, not extract attention or data. These principles guide product decisions from architecture to interface.

01 / PRIVACY

Your data stays yours.

Apps are designed to avoid unnecessary data collection and external dependencies.

  • No advertising or analytics SDKs by design
  • No mandatory registration or phone number
  • Local storage for core application data
02 / OFFLINE-FIRST

Useful without a connection.

Core workflows should remain dependable even when the network is unavailable.

  • Local-first application architecture
  • No mandatory cloud account for core use
  • Network access kept out of essential workflows where possible
03 / ACCESSIBILITY

Clear, focused interfaces.

Interfaces prioritise readable information, predictable navigation and practical everyday use.

  • Responsive layouts and touch-friendly controls
  • Light and dark appearance where supported
  • Careful empty, error and confirmation states
04 / TRANSPARENCY

Open development.

Project repositories make implementation, progress and feedback visible.

  • Public source repositories
  • Documented development milestones
  • Issues and feature discussions on GitHub
