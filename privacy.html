Privacy policy

This page describes the privacy practices of the SuBZeRo developer website. It does not replace the separate privacy policy that will be published for each Q Apps application.

Information collected

This is a static information website. It does not provide visitor accounts, contact forms, advertising, analytics or newsletter subscriptions. It does not intentionally collect personal information through its own website code.

Hosting and server logs

If hosted using GitHub Pages, GitHub may process technical information such as IP addresses in server logs for security and service operation. Hosting provider privacy terms apply.

External links

This website links to GitHub and other external services. When you follow those links, the destination service's privacy policy and terms apply. This website does not control those services.

Cookies and tracking

The website does not intentionally set advertising or analytics cookies and does not embed third-party analytics scripts.

Application privacy

Each application may have different functionality, permissions and data handling. Its own privacy policy and store disclosures must describe its actual behaviour, including any third-party SDKs. Do not rely on this website policy as an app privacy disclosure.

Contact

For privacy questions about this website, please open a discussion through the SuBZeRo GitHub profile.
